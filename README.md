# 季節の天気あて（kisetsu-tenki）

天気図や天気のようす（西高東低・北西の季節風・移動性高気圧・停滞前線・南高北低・最大風速 など）を見て、冬・春と秋・つゆ・夏・台風のどれかを当てる1日5問の学習ゲーム。正解したら「もとになる空気は？」（冷たく乾いた大陸の空気・温かい海の空気・冷たい空気と温かい空気の境目）も選ぶ。中学2年理科「日本の天気」。

遊ぶ: <https://satou-aaaaa.github.io/kisetsu-tenki/>

- 中身は千葉県教育委員会「やる気アップ 理科」の日本の天気のプリント（解答）、横浜市立中学校の学習課題（解答）、気象庁の予報用語・気象庁キッズで確かめたことだけです。
